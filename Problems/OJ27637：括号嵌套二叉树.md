前序遍历就是字符串顺序，中序遍历以‘，’为界，按左中右合并字符串。注意删掉*

```python
n=int(input())
for _ in range(n):
    pre = []
    stack = []
    for ch in input():
        if ch==')':
            r=stack.pop()
            stack.pop()
            l=stack.pop()
            stack.pop()
            root=stack.pop()
            stack.append(l+root+r)
        else:
            stack.append(ch)
            if ch not in ['(',',']:
                pre.append(ch)
    pres=''.join(pre).replace('*','')
    mid=''.join(stack).replace('*','')
    print(pres)
    print(mid)
```
