维护两个队列，使他们长度相等。一个是单减队列，使得滑动窗口内最大的数永远在最左边，一个记录每个数字入队时挤出队的数字的数量。窗口滑动时，每次在右边加入一个数字，在左边去掉一个数字，去掉时，如果被这个数字挤出队的数字数量不为零，那么就把数量减一；如果为零，就将两个队列最左边的元素都出队。

```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        from collections import deque
        queue=deque()
        l=deque()
        for num in nums[:k]:
            re=0
            while queue and queue[-1]<num:
                queue.pop()
                re+=(l.pop()+1)
            queue.append(num)
            l.append(re)
        ans=[queue[0]]
        for num in nums[k:]:
            re=0
            while queue and queue[-1]<num:
                queue.pop()
                re+=(l.pop()+1)
            queue.append(num)
            l.append(re)
            if l[0]>0:
                l[0]-=1
            else:
                l.popleft()
                queue.popleft()
            ans.append(queue[0])
        return ans
```
