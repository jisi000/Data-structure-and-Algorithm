用x，y指示当前要标定的位置，i表示要标的数字，按题目要求计算下一次的x和y。

```python
n=int(input())
N=(2*n)-1
matrix=[[0]*N for _ in range(N)]
x,y=0,n-1
for i in range(1,N*N+1):
    matrix[x][y]=i
    if x==0 and y==N-1:
        x+=1
        continue
    dx,dy=(x-1)%N,(y+1)%N
    if matrix[dx][dy]!=0:
        dx,dy=x+1,y
    x,y=dx,dy
for row in matrix:
    print(*row)
```
