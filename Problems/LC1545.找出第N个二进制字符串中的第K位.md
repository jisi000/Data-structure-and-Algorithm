对于奇数位，都由S1=0衍生而来，是一个010101的交替串。

对于偶数位，是由每次添加的1衍生而来，每个都会衍生成101010的交替串。只需要找到在这个串中当前数字位于哪一位。观察到这些1在串中的初始位置都是2、4、8等整二进制数，当衍生到下一个串时，观察到串的长度都是(2^n-1)，那么衍生数在串中位置为k和(2^n-1)-k+1=2^n-k，这两个索引的尾0数目是一样的。以此类推，一个1的衍生数在串中的索引尾0数目都一样，而第一个数索引都是原先的2、4、8，去掉尾零后变成1，因此对k去尾零即可得到从1开始的顺序。

```python
class Solution:
    def findKthBit(self, n: int, k: int) -> str:
        if k%2:
            return str(k//2%2)
        k//=k&-k
        return str(1-k//2%2)
```
