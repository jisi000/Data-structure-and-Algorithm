假设水平分割，如果dif=re*2-total是0或者是上面的一个数字，就是可行的分割。用num记录上面的所有数字。按行遍历，同时完成num和re的更新，计算出当前的dif。对特殊情况单独处理：当列数只有1时，只有列两端的数字可以删除；当前面只有一行时，，只有第一行两端的数字可以删除。

只删除上部数字的水平分割，也可以由其他情况转化而来，只需要进行矩阵的旋转list(zip(*matrix))和翻转matrix[::-1]操作。

```python
class Solution:
    def canPartitionGrid(self, grid: List[List[int]]) -> bool:
        total=sum([sum(row) for row in grid])
        def check(matrix):
            r,c=len(matrix),len(matrix[0])
            num={0}
            re=0
            for i,row in enumerate(matrix[:-1]):
                num.update(row)
                re+=sum(row)
                dif=2*re-total
                if dif<0:
                    continue
                if c==1:
                    if dif in {0,matrix[0][0],row[0]}:
                        return True
                    continue
                if i==0:
                    if dif in {0,row[0],row[-1]}:
                        return True
                    continue
                if dif in num:
                    return True
            return False
        return check(grid) or check(list(zip(*grid))) or check(grid[::-1]) or check(list(zip(*grid))[::-1])
```
