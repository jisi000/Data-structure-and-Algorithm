Manacher算法。要计算的是以每个字符为中心的最长回文半径。根据回文序列的性质，在一个大回文串中左右两边对称，因此知道左边的字符中心回文半径，就能把这个半径映射到右边。只需在边界外继续检查即可保证得到正确的回文半径。用halfl记录回文半径，r记录当前最远边界，c记录这个边界对应的回文中心。

因为回文串有奇书长度和偶数长度，在每个字符中间插入‘#’使他们统一成奇数长度的回文串。

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        s1='#'.join('^'+s+'&')
        halfl=[0]*(len(s1)-2)
        halfl[1]=1
        ans=0
        c,r=0,0
        for i in range(2,len(s1)-2):
            l=1
            if i<=r:
                l=min(halfl[(2*c)-i],r-i+1)
            while s1[i-l]==s1[i+l]:
                l+=1
                c=i
                r=i+l-1
            halfl[i]=l
            ans+=l//2
        return ans 
```
