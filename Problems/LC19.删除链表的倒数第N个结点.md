先遍历整个链表，确定链表的长度。然后计算倒数第n个节点是正数的第t个节点。建立哨兵节点，找到删除节点的前一个节点，执行a.next=a.next.next。

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        count=0
        c=head
        while c:
            count+=1
            c=c.next
        t=count-n
        pos=a=ListNode()
        a.next=head
        for _ in range(t):
            a=a.next
        a.next=a.next.next
        return pos.next
```
