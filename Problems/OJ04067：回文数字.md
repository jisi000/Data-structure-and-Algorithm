使用双端队列是判断单个回文串的好方法。

```python
from collections import deque
def pal(s):
    n=deque(list(s))
    while len(n)>1:
        if n.popleft()!=n.pop():
            return False
    return True
while True:
    try:
        inp=input()
        if pal(inp):
            print('YES')
        else:
            print('NO')
    except EOFError:
        break
```
