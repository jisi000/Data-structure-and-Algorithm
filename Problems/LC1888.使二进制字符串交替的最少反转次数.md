因为操作1可以执行无限次，把原字符串*2，代表不同的操作1次数，在其中维护长度位n的滑动窗口。因为字符串中只有零和一，假设变成0101的交替串，只需记录索引模二与该位置的数字不同的索引数c。若变成1010串，则不同的索引数就是n-c。找到所有的c和n-c中最小的。

```python
class Solution:
    def minFlips(self, s: str) -> int:
        n=len(s)
        sl=list(map(int,list(s*2)))
        c=0
        ans=n
        for i in range(n):
            if i&1==sl[i]:
                c+=1
        l=0
        while l<n:
            ans=min(ans,c,n-c)
            if l&1==sl[l]:
                c-=1
            if (l+n)&1==sl[l+n]:
                c+=1
            l+=1
        return ans
```
